# React Developer Portfolio Card

A responsive and interactive developer portfolio card built using **React.js**. This project was created as part of my React learning journey to practise component-based development, props, state management, and event handling.

## Overview

The application presents developer profile information through a clean portfolio card interface. It includes interactive features that allow users to switch themes, change the profile picture, and interact with a like counter.

## Features

- **Profile Information:** Displays developer name, role, location, email, and introduction.
- **Reusable Components:** Organizes the application into separate React components.
- **Dynamic Data with Props:** Passes profile information and skills between components.
- **Light and Dark Mode:** Allows users to switch between two themes.
- **Interactive Profile Photo:** Change the displayed profile picture.
- **Like Counter:** Updates the like count through user interaction.
- **Event Handling:** Responds to button clicks and user actions.
- **Responsive Design:** Provides a layout suitable for different screen sizes.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd portfolio-card
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

The application will open at:

`http://localhost:3000`
